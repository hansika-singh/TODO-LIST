## 📌 About The Project

**TODO List** is a beginner-friendly task management web application created using vanilla HTML, CSS and JavaScript.

The project focuses on learning and implementing fundamental frontend development concepts such as **DOM manipulation, event handling, dynamic element creation, browser storage and JavaScript functions**.

Users can add tasks, mark them as completed, delete them, and keep their tasks saved even after refreshing the page.
